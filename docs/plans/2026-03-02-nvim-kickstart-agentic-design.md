# Neovim Kickstart + Agentic Coding Setup

## Goal

Replace the current custom nvim config with stock kickstart.nvim, then add GitHub Copilot and agentic workflow optimizations for use alongside Claude Code.

## Decisions

- **Base:** Stock kickstart.nvim init.lua (lazy.nvim, blink.cmp, Telescope, Treesitter, Mason, conform, gitsigns, which-key, mini.nvim)
- **Theme:** Catppuccin Macchiato (consistent with Ghostty terminal and Starship prompt)
- **Copilot UX:** Completions in blink.cmp menu only (no ghost text)
- **Agentic model:** Claude Code in terminal, nvim as editor
- **Languages:** Primarily TypeScript/JavaScript with Tailwind CSS

## Architecture

### Base Configuration

Stock kickstart.nvim `init.lua` with one theme swap: `tokyonight` replaced by `catppuccin/nvim` (Macchiato flavor, transparent background).

All kickstart defaults retained: leader=Space, relative line numbers, search settings, clipboard sync, etc.

### Copilot Integration

Two plugins working together:

1. **copilot.lua** — Copilot LSP client. `suggestion.enabled = false`, `panel.enabled = false` (completions routed through blink.cmp instead).
2. **blink-cmp-copilot** — Bridges copilot.lua into blink.cmp's completion menu. `score_offset = 100`, `async = true`. Copilot appears as a source alongside LSP/snippets/paths.

blink.cmp sources: `{ "lsp", "path", "snippets", "buffer", "copilot" }`

### Agentic Workflow Optimizations

**Auto-reload on external changes:**
- `vim.opt.autoread = true` (already in kickstart)
- `FocusGained` + `BufEnter` autocommands running `checktime` so files edited by Claude Code reload silently when switching back to nvim

**diffview.nvim:**
- `<leader>gd` — diff of unstaged changes (review what Claude Code just did)
- `<leader>gh` — file history
- Integrates with gitsigns

**oil.nvim:**
- `-` opens parent directory as a buffer
- Navigate to new files Claude Code created
- Replaces netrw

### LSP Configuration

Servers auto-installed via Mason + mason-tool-installer:
- `ts_ls` — TypeScript/JavaScript
- `eslint` — Linting
- `tailwindcss` — Tailwind CSS intellisense
- `lua_ls` — Lua (for editing nvim config)

Formatters via conform.nvim:
- `prettier` for JS/TS/JSON/CSS/HTML files

### What's Removed (vs current config)

- neotest (Jest test runner)
- nvim-dap (debugging)
- nvim-autopairs
- nvim-ts-autotag
- lualine (replaced by mini.statusline)
- Comment.nvim (replaced by mini.comment)
- nvim-treesitter-textobjects (replaced by mini.ai)

These can be added back later if needed.
